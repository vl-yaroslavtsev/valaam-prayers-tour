# Инструкция по развертыванию

## Безопасная настройка учетных данных

Этот проект использует переменные окружения для хранения конфиденциальных данных развертывания (SSH-ключи, учетные данные серверов).

### Первоначальная настройка

1. **Создайте файл с переменными окружения:**
   ```cmd
   copy scripts\deploy.env.example scripts\deploy.env
   ```

2. **Отредактируйте `scripts\deploy.env`:**
   Откройте файл и замените примеры на реальные значения:
   - Пути к SSH-ключам
   - Имена пользователей
   - Пути к папкам на серверах

3. **Загрузите переменные окружения:**
   ```cmd
   call scripts\deploy.env
   ```

### Развертывание

#### DEV окружение
```cmd
call scripts\deploy.env && npm run deploy-dev
```

#### TEST окружение
```cmd
call scripts\deploy.env && npm run deploy-test
```

#### PRODUCTION окружение
```cmd
call scripts\deploy.env && npm run deploy
```

### Необходимые переменные окружения

#### Для DEV:
- `DEPLOY_DEV_SSH_KEY` - путь к SSH-ключу
- `DEPLOY_DEV_USER` - пользователь@сервер
- `DEPLOY_DEV_REMOTE_FOLDER` - папка на сервере

#### Для TEST:
- `DEPLOY_TEST_SSH_KEY` - путь к SSH-ключу
- `DEPLOY_TEST_REMOTE` - пользователь@сервер
- `DEPLOY_TEST_REMOTE_FOLDER` - папка на сервере

#### Для PRODUCTION:
- `DEPLOY_PROD_SSH_KEY` - путь к SSH-ключу
- `DEPLOY_PROD_USER` - пользователь@сервер
- `DEPLOY_PROD_REMOTE_FOLDER` - папка на сервере

## Безопасность

⚠️ **ВАЖНО:**
- Файл `deploy.env` содержит конфиденциальные данные и добавлен в `.gitignore`
- **НИКОГДА** не коммитьте файл `deploy.env` в репозиторий
- Храните SSH-ключи в безопасном месте
- Не передавайте учетные данные через незащищенные каналы

## Альтернативные методы

### Системные переменные окружения (Windows)

Вы можете установить переменные на уровне системы:

```cmd
setx DEPLOY_DEV_SSH_KEY "C:\Users\YourName\.ssh\id_rsa_dev"
setx DEPLOY_DEV_USER "user@server.com"
setx DEPLOY_DEV_REMOTE_FOLDER "/var/www/data"
```

После этого переменные будут доступны во всех новых сеансах командной строки.

### Постоянные переменные пользователя

Вы также можете добавить переменные через:
1. Панель управления → Система → Дополнительные параметры системы
2. Переменные среды
3. Добавить новые переменные пользователя

## Устранение неполадок

### Ошибка: "Не установлена переменная окружения"

Убедитесь, что:
1. Вы создали файл `scripts\deploy.env`
2. Выполнили команду `call scripts\deploy.env` перед развертыванием
3. Все необходимые переменные заданы в файле

### Ошибка SSH-подключения

Проверьте:
1. Правильность пути к SSH-ключу
2. Права доступа к SSH-ключу
3. Доступность сервера
4. Корректность имени пользователя
